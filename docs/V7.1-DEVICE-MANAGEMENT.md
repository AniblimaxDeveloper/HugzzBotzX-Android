# V7.1 Device Management

## Wireless ADB sequence
1. The target device owner enables Developer options → Wireless debugging.
2. The owner opens Pair device with pairing code.
3. Enter the displayed IP and pairing port in HugzzBotzX.
4. Copy `adb pair HOST:PAIR_PORT` to Termux and run it. Enter the temporary code only at the Termux prompt.
5. Return to the target's Wireless debugging main page and read its separate connection port.
6. Save the connection port in the HugzzBotzX device profile.
7. Copy `adb connect HOST:CONNECT_PORT`; then inspect `adb devices -l`.

HugzzBotzX does not store the one-time pairing code or execute shell commands. Read-only diagnostics are copied to the clipboard for review.

## Revocation
Remove the workstation from the paired devices list on the target device. Deleting the local HugzzBotzX record only removes this app's note.

## Support session records
A support session record requires the user to confirm current owner approval and describe its purpose. The record includes device alias, start and end timestamps and duration. This is an audit record only, not a remote-control transport.
