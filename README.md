# HugzzBotzX DevLab V6.0 — Comic Command

Premium full-color comic UI using the supplied HugzzBotzX logo.

## Real features
- Device diagnostics: Android version, model, memory, storage, battery, network.
- Flashlight and a slow, time-limited SOS pattern.
- Usage Access shortcut for Android screen-time statistics.
- Installed-app inventory.
- Local parent PIN and family routines.
- Local activity log and shareable diagnostic report.
- Wireless ADB authorization-first workflow.
- Safe local Bug Lab: bounded CPU test, 4 MB memory test, caught exception demo.

## Safety
Remote control is not enabled silently. ADB requires the target device to enable and authorize Wireless Debugging. Bug Lab is for a device/emulator you own or are authorized to test.

## Build
Use JDK 17 + Gradle 9.6 + Android Gradle Plugin 9.5.0.
